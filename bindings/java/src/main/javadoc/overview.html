KMIPKit Java API

KMIPKit is a memory-safe, specification-driven OASIS KMIP 2.0, 2.1, and 3.0 client library for Java 17+, backed by the authoritative KMIPKit Rust core via a thin JNI bridge.

Package Summary

  • {@link org.kmipkit.fluent} — Task-oriented Fluent Builders for symmetric/asymmetric keys, crypto operations, and lifecycle management.
  • {@link org.kmipkit.extensions} — Typed {@code Client}, {@code ClientBatch}, {@code TransportConfiguration}, Server-to-Client listeners, and Vendor Extension registries.
  • {@link org.kmipkit.credentials} — Zeroizing {@code Authentication}, {@code SecretBytes}, {@code SecretText}, and credential models.
  • {@link org.kmipkit.protocol} — Normative KMIP 2.0/2.1/3.0 enumerations, bitmasks, and cryptographic parameter builders.
  • {@link org.kmipkit.ttlv} — Generic ordered TTLV item tree and bounded codecs.

Resource Management

All native-backed classes implement {@link java.lang.AutoCloseable}. Always manage them inside {@code try-with-resources} blocks to guarantee deterministic memory release and secret zeroization.
