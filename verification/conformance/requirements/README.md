# Requirement traceability

The CSV files retain the requirement identifiers, normative or project sources, scope, implementation references, tests, and evidence states imported from `release/1.0.0`. Repository paths have been updated to the review layout.

These matrices are historical evidence inputs. Their recorded states do not replace executing the referenced checks against the current commit. References to feature plans, ADRs, or policy sources on the full development branch remain explicit dependencies; those documents are not included in this directory.

Dependency policy exceptions are maintained separately in `verification/dependencies/dependency-policy-exceptions.json`.
