# OASIS KMIP 3.0 profile XML fixtures

These files were supplied for the KMIPKit interoperability matrix. The relative
paths match all test case links in the pinned OASIS KMIP 3.0 Working Draft
profiles document. See the [source inventory](../../../../conformance/oasis/kmip-3.0/SOURCES.md)
for the document revision and checksums. The upstream case paths have the prefix
`test-cases/kmip-v3.0/`. The checksums in this directory identify the supplied
copies. The mandatory and optional categories follow the upstream paths.
