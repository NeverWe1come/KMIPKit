# OASIS KMIP 2.0 profile XML fixtures

These files were supplied for the KMIPKit interoperability matrix. See the
[pinned OASIS source inventory](../../../../../conformance/oasis/kmip-2.0/SOURCES.md)
for the profiles revision. Upstream case paths have the prefix
`test-cases/kmip-v2.0/`. The checksums identify the supplied copies.
The categories follow the upstream directory names.

The profiles document lists the case `CS-BC-M-13-20` in §5.9.7.13.
That section links to the M-14 XML, so the inventory explicitly includes the
supplied M-13 XML alongside the 92 distinct files linked by the document.
