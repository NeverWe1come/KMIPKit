# KMIPKit Eclipse IDE Plugin (`ide-plugins/eclipse/`)

OSGi plugin built on **Eclipse LSP4E** (`org.eclipse.lsp4e`) and **Maven Tycho**, connecting Eclipse Java, CDT (C/C++), and JSON editors to `kmip-lsp --stdio`.

## Build (JDK 21 + Maven 3.9+)
```bash
mvn -f ide-plugins/eclipse/pom.xml verify
```
