# Specification data

This tree contains inputs and evidence for Spec Driven Development. It is
separate from the installed Spec Kit framework, which the maintainer owns.

- `oasis/`: immutable upstream OASIS work products.
- `catalog/`: future reviewed machine-readable KMIP 2.1 catalog.
- `compliance/`: future requirement and profile traceability data.

Builds must use checked-in reviewed inputs. They must not download or scrape
standards documents.
