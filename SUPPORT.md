# Support

KMIPKit is not yet released for production use.

After the public 1.0 release:

- Use GitHub Discussions for usage questions and design discussion.
- Use issue forms for reproducible bugs, feature proposals, and server
  interoperability reports.
- Use the private process in `SECURITY.md` for suspected vulnerabilities.

The latest stable release is the supported release. The project initially
operates without a response SLA. Commercial support is not provided by the
project unless announced separately.

When requesting help, include the KMIPKit version, language adapter, operating
system and architecture, transport, sanitized configuration, server product
and version, and a minimal reproduction. Never attach credentials, keys, raw
secret-bearing TTLV, or proprietary diagnostics.
