## 1. Normative Purpose

Executes the Query Asynchronous Requests operation according to OASIS KMIP 2.1 §6.1.41.

## 3. Common Errors (ResultReason)

| ResultStatus | ResultReason | Description |
| :--- | :--- | :--- |
| `OperationFailed` | `ItemNotFound` | The requested object does not exist. |
| `OperationFailed` | `PermissionDenied` | The client credentials lack sufficient permissions. |
| `OperationFailed` | `CryptographicFailure` | Cryptographic failure during algorithm execution. |
