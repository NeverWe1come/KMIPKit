## 2. Thales CipherTrust Manager

1. **Interface Configuration**:
   - In CipherTrust Manager, navigate to **Admin Settings > Interfaces > KMIP**.
   - Enable standard port `5696` and require TLS 1.3 mutual authentication.
2. **Client Certificate Registration**:
   - Upload the corporate issuing CA to the CipherTrust Local CA pool.
   - Attach a KMIP Access Policy mapped to the client certificate Common Name (CN) or SAN.
3. **Specifics**:
   - Requires explicit `CryptographicUsageMask` flags during symmetric key creation.

---

## 3. Utimaco ESKM

1. **mTLS Setup**:
   - Export the ESKM root CA certificate from the management console.
   - Register the client certificate within the designated KMIP Client Group.
2. **Supported Features**:
   - 100% interoperable for AES symmetric key creation, activation, derivation, and destruction.
