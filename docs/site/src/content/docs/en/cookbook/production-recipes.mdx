## 1. Strict mTLS Configuration and Hot-Reload

KMIPKit enforces **TLS 1.3** and mutual certificate authentication via `rustls` and `aws-lc-rs`:

<Tabs syncKey="lang">
  <TabItem label="Rust" icon="rust">
```rust
use kmipkit::config::{ClientConfig, TlsConfig};

let tls = TlsConfig::builder()
    .ca_certificate_file("/etc/ssl/certs/kmip-ca.pem")
    .client_certificate_file("/etc/ssl/certs/client.crt")
    .client_key_file("/etc/ssl/private/client.key")
    .server_name("kms.prod.bank.internal") // Strict SAN hostname verification
    .crl_file("/etc/ssl/crl/root.crl")      // Explicit revocation list
    .build()?;
```
  </TabItem>
  <TabItem label="Python" icon="python">
```python
from kmipkit import TlsConfig

tls = TlsConfig(
    ca_file="/etc/ssl/certs/kmip-ca.pem",

    key_file="/etc/ssl/private/client.key",
    server_name="kms.prod.bank.internal",
    crl_file="/etc/ssl/crl/root.crl",
)
```

## 2. Batch Processing with `IDPlaceholder`

Execute multiple operations in a **single network round-trip**, linking the result of one operation into subsequent items:

```rust
use kmipkit::client::Client;
use kmipkit::models::{BatchErrorContinuationOption, SymmetricAlgorithm, CryptographicUsage};

let batch_outcome = client.batch()
    .error_continuation(BatchErrorContinuationOption::Stop)
    // 1. Create key and assign IDPlaceholder = 1
    .create_symmetric_key()
        .assign_placeholder(1)
        .algorithm(SymmetricAlgorithm::Aes)
        .length_bits(256)
        .usage(CryptographicUsage::ENCRYPT | CryptographicUsage::DECRYPT)
        .add()
    // 2. Activate referencing placeholder 1
    .activate()
        .target_placeholder(1)
        .add()
    // 3. Fetch attributes referencing placeholder 1
    .get_attributes()
        .target_placeholder(1)
        .add()
    .execute()?;

println!("Successfully executed batch with {} operations", batch_outcome.len());
```

## 3. Protocol Asynchronous Operations

For long-running HSM operations (e.g., RSA-4096 key pair generation or split-key computation):

```rust
// Dispatch request with asynchronous indicator
let pending = client.create_key_pair()
    .asynchronous(true)
    .execute_async()?;

println!("Pending operation correlation: {}", pending.correlation_value());

// Poll periodically until complete
let outcome = pending.wait(std::time::Duration::from_millis(500), std::time::Duration::from_secs(30))?;
println!("Key pair generated: {:?}", outcome);
```

## 4. Vendor Extensions

Register and serialize proprietary tags in the range `0x540000`–`0x54FFFF` without violating type safety:

```rust
use kmipkit::extensions::{VendorExtensionRegistry, ExtensionTag};

let mut registry = VendorExtensionRegistry::new();
registry.register_tag(
    ExtensionTag::from_u32(0x540001).unwrap(),
    "x-vendor-custom-policy",
);
```
