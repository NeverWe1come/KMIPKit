## 1. Configuración Estricta de mTLS y Hot-Reload

KMIPKit utiliza `rustls` y `aws-lc-rs` forzando **TLS 1.3** y autenticación mutua de certificados:

<Tabs syncKey="lang">
  <TabItem label="Rust" icon="rust">
```rust
use kmipkit::config::{ClientConfig, TlsConfig};

let tls = TlsConfig::builder()
    .ca_certificate_file("/etc/ssl/certs/kmip-ca.pem")
    .client_certificate_file("/etc/ssl/certs/client.crt")
    .client_key_file("/etc/ssl/private/client.key")
    .server_name("kms.prod.bank.internal") // Validación estricta de SAN
    .crl_file("/etc/ssl/crl/root.crl")      // Lista de revocación explícita
    .build()?;
```
  </TabItem>
  <TabItem label="Python" icon="python">
```python
from kmipkit import TlsConfig

tls = TlsConfig(
    ca_file="/etc/ssl/certs/kmip-ca.pem",
    cert_file="/etc/ssl/certs/client.crt",
    key_file="/etc/ssl/private/client.key",
    server_name="kms.prod.bank.internal",
    crl_file="/etc/ssl/crl/root.crl",
)
```

## 2. Procesamiento en Lotes (Batching) con `IDPlaceholder`

Ejecuta múltiples operaciones en **un solo viaje de red** (*round-trip*), encadenando el resultado de una operación con la siguiente:

```rust
use kmipkit::client::Client;
use kmipkit::models::{BatchErrorContinuationOption, SymmetricAlgorithm, CryptographicUsage};

let batch_outcome = client.batch()
    .error_continuation(BatchErrorContinuationOption::Stop)
    // 1. Crear clave y asignar IDPlaceholder = 1
    .create_symmetric_key()
        .assign_placeholder(1)
        .algorithm(SymmetricAlgorithm::Aes)
        .length_bits(256)
        .usage(CryptographicUsage::ENCRYPT | CryptographicUsage::DECRYPT)
        .add()
    // 2. Activar usando el IDPlaceholder 1
    .activate()
        .target_placeholder(1)
        .add()
    // 3. Obtener atributos usando el IDPlaceholder 1
    .get_attributes()
        .target_placeholder(1)
        .add()
    .execute()?;

println!("Lote procesado exitosamente: {} operaciones", batch_outcome.len());
```

## 3. Operaciones Asíncronas del Protocolo

Para operaciones lentas en HSMs físicos (como generación de pares de claves RSA-4096 o división de claves):

```rust
// Enviar petición con indicador asíncrono
let pending = client.create_key_pair()
    .asynchronous(true)
    .execute_async()?;

println!("Operación pendiente con CorrelationValue: {}", pending.correlation_value());

// Consultar periódicamente (Poll) hasta completar
let outcome = pending.wait(std::time::Duration::from_millis(500), std::time::Duration::from_secs(30))?;
println!("Par de claves generado: {:?}", outcome);
```

## 4. Extensiones de Fabricante (Vendor Extensions)

Registra y procesa etiquetas propietarias en el rango `0x540000`–`0x54FFFF` sin romper la seguridad de tipos:

```rust
use kmipkit::extensions::{VendorExtensionRegistry, ExtensionTag};

let mut registry = VendorExtensionRegistry::new();
registry.register_tag(
    ExtensionTag::from_u32(0x540001).unwrap(),
    "x-vendor-custom-policy",
);
```
