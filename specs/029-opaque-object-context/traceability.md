# Opaque Object Register Context Traceability

This ledger maps each normative requirement used by KMIPKIT-0044 to the pinned
OASIS KMIP 2.1 source, implementation, and exact positive and negative Rust
tests. The six Register Table 293 requirement IDs remain owned by KMIPKIT-0036
in the normative catalog; this feature adds context-specific evidence without
changing that ownership. No requirement-specific official OASIS Test Cases ID
is linked to these clauses, so these are project-derived tests, not official
test-case passes.
